# Family Fitness Quest — Unity & C# Portfolio

A collection of four functional Unity prototypes demonstrating gameplay programming, persistent player progression, performance monitoring, simulated health telemetry, and local cooperative mechanics.

## Technology

- Unity 6.3 LTS
- C#
- TextMesh Pro
- Unity UI
- Universal Render Pipeline (2D)
- PlayerPrefs, coroutines, JSON parsing, and object pooling

## Prototypes

### 1. Family Fitness Quest

A fitness challenge prototype featuring:

- Exercise-based XP progression
- Daily challenge tracking
- Player streak and progress persistence
- Local data storage using PlayerPrefs

### 2. Mobile Performance Lab

A real-time performance testing scene featuring:

- FPS and frame-time monitoring
- Allocated-memory display
- Object-pooling stress test
- 300 reusable colored sprite objects

### 3. Health Telemetry Dashboard

A simulated health-data dashboard featuring:

- Heart-rate monitoring
- Step, calorie, and distance tracking
- Locally simulated JSON telemetry
- Start and stop live-data controls

### 4. Family Co-op Challenge

A local two-player cooperative game featuring:

- Individual Player 1 and Player 2 scoring
- Shared team objective
- 30-second countdown timer
- Win state and replay functionality

## Running the Project

1. Install Unity 6.3 LTS or a compatible Unity 6 version.
2. Clone or download this repository.
3. Open the project through Unity Hub.
4. Open a scene from `Assets/Scenes`.
5. Press Play in the Unity Editor.

## Project Structure

- `Assets/Scenes` — Unity scenes
- `Assets/*.cs` — gameplay and monitoring scripts
- `Packages` — Unity package configuration
- `ProjectSettings` — Unity project configuration
